# Behancer Bot

Настольное приложение для выполнения заданий `@behancer_bot`: получает ссылку из Telegram, открывает её в установленном Google Chrome с пользовательским профилем, находит проект Behance и выполняет задание — ставит лайк или оставляет комментарий на английском.

## Требования

- Windows 10/11;
- Python 3.11+;
- установленный Google Chrome;
- Telegram API ID и API Hash с [my.telegram.org](https://my.telegram.org/).

## Установка и запуск

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

После установки на Windows можно запускать приложение двойным щелчком по `run_bot.bat`. В заголовке и первых строках лога отображаются версия и полный путь к запущенному коду — это помогает исключить запуск старой копии.

## Переносимая версия

Распакуйте архив `BehancerBot-portable.zip` в отдельную папку и запустите
`BehancerBot.exe`. Устанавливать Python и библиотеки не требуется; нужен только
установленный Google Chrome. Настройки, Telegram-сессии и управляемые профили
Chrome сохраняются рядом с программой, поэтому папку после первого запуска не
следует переносить во время работы приложения.

В окне укажите API ID, API Hash, телефон в международном формате и папку данных Chrome. Доступные пользовательские профили Chrome загружаются автоматически в выпадающий список; рядом есть кнопка «Обновить». В списке показываются понятное имя профиля и имя его папки, например `Рабочий — Profile 2`.

Перед первым запуском выбранного профиля нажмите «Открыть для входа» и авторизуйтесь во всех нужных социальных сетях в появившемся управляемом окне. После входа cookies сохраняются в постоянном профиле автоматизации и используются при следующих запусках.

При первом запуске приложение запросит код Telegram и, если включено, пароль 2FA. Сессия сохраняется в `.data/sessions` под именем, составленным из номера телефона. Настройки сохраняются локально в `config.json`; оба пути исключены из Git.

## Важное о Chrome

Selenium использует установленный Chrome, но никогда не подключается к обычным рабочим окнам и не закрывает их. Для автоматизации приложение всегда создаёт отдельное управляемое окно на локальной копии выбранного профиля в `.data/chrome-user-data`. Копия создаётся только при первом запуске профиля; если Behance не перенёс авторизацию, войдите в аккаунт один раз в управляемом окне.

Начиная с Chrome 136, cookies и сохранённые пароли обычного профиля защищены отдельным ключом и не могут быть перенесены в каталог с отладкой простым копированием. Поэтому вход через кнопку «Открыть для входа» выполняется один раз отдельно для управляемого профиля.

Каждый выбранный профиль получает отдельный локальный отладочный порт и отдельную рабочую копию. Поэтому уже открытое управляемое окно одного профиля не мешает выбрать и открыть другой профиль.

Управляемое окно остаётся открытым после «Стоп», а при следующем старте с тем же профилем приложение повторно подключается к нему. Рабочий и управляемый Chrome могут использоваться одновременно.

Если используется не основной профиль, его имя можно найти на странице `chrome://version` в строке «Путь к профилю» — последняя часть пути обычно выглядит как `Profile 1`.

## Управление

- **Старт** подключает Telegram и запускает Chrome; счётчики обнуляются.
- **Пауза** приостанавливает управляемые ожидания и действия.
- **Возобновить** снимает паузу.
- **Пропустить** прерывает текущее задание и нажимает соответствующую кнопку бота.
- **Стоп** отключает Telegram и отпускает Chrome, не закрывая его окно.

Следующее задание запрашивается только после успешного нажатия «Готово». Если подтверждение не удалось, приложение останавливается, чтобы не потерять текущее задание.

После нажатия «Готово» приложение до 10 секунд ждёт результат проверки бота. Ответы «лайк не найден», «комментарий не найден» и сообщения о теневом бане автоматически переводят задание в пропущенные: приложение нажимает «Пропустить» и переходит к следующему заданию.

Задания на лайк со ссылкой на Facebook автоматически пропускаются без открытия Chrome. Задания на комментарий со ссылкой на пост Facebook открываются: приложение ищет в посте проект Behance и публикует там комментарий из локального словаря. Один и тот же текст не повторяется, пока словарь не будет использован целиком.

Если прямую Behance-ссылку определить нельзя, приложение последовательно кликает по всем видимым URL в тексте поста. После каждого редиректа проверяется итоговая страница: проект Behance используется для задания, а для остальных страниц приложение закрывает новую вкладку или возвращается назад и проверяет следующую ссылку.

Перед первым поиском ссылки Behance на любой внешней странице приложение ждёт 5 секунд. Ожидание прерывается командами «Пропустить» и «Стоп» и приостанавливается вместе с общей паузой.
