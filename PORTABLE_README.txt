Behancer Bot v1.5.2 — переносимая версия

1. Полностью распакуйте архив в отдельную папку.
2. Убедитесь, что на компьютере установлен Google Chrome.
3. Запустите BehancerBot.exe.
4. Введите собственные Telegram API ID, API Hash и номер телефона.
  "api_id": 30231723,
  "api_hash": "209ca4a4edeb22fd6f0b957435b33c26",
  "phone": "+79064484422"
   API-данные можно получить на https://my.telegram.org/.
5. Выберите профиль Chrome и нажмите «Открыть для входа», чтобы один раз
   авторизоваться в Behance и нужных социальных сетях.
6. После авторизации нажмите «Старт».

Python и дополнительные библиотеки устанавливать не требуется.

Программа создаёт config.json и папку .data рядом с BehancerBot.exe. В них
хранятся настройки, Telegram-сессия и управляемый профиль Chrome. Не передавайте
эти файлы другим людям после авторизации и не запускайте программу прямо из ZIP.

Windows может показать предупреждение SmartScreen, потому что EXE не подписан
платным сертификатом издателя. Проверяйте архив перед запуском антивирусом.
